# YouTube UI Clone

A recreation of the YouTube homepage interface built with HTML and CSS.

This project was created to practice front-end development fundamentals, with a focus on page layout, responsive design, and reusable CSS styling.

## Features

- YouTube-inspired homepage layout
- Header with search bar and navigation icons
- Sidebar navigation
- Video preview grid
- Channel profile images and video information
- Responsive layout

## Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox

## What I Practiced

Through this project, I practiced structuring web pages with HTML, creating layouts with CSS Grid and Flexbox, organizing styles into separate files, and recreating a real-world user interface.
